Channel icons shown on the strip name tags, 24x24 stroke SVGs in one style:
- Lucide (https://lucide.dev, ISC licence, LICENSE-lucide.txt): most of them.
- Tabler Icons (https://tabler.io/icons, MIT, LICENSE-tabler.txt): broadcast, metronome,
  microphone-2, music, vinyl.
- Drawn for Openface Mixer in the same style: accordion, amp, bass, bongos, flute, harmonica,
  harp, saxophone, trumpet, ukulele, upright-bass, violin.
Add an icon by dropping an SVG here and listing it in theme.CHANNEL_ICONS.
